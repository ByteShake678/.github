# Contributing

Thanks for helping improve the ByteShake678 organization page.

## Profile changes

1. Update `profile/README.md` or the relevant file under `assets/`.
2. Run `python3 scripts/validate_profile.py`.
3. Open a focused pull request and describe the visible change.

Keep the public profile concise. Introduce a project only after it has a public repository or a usable link.

## Review checklist

- The copy is specific and avoids unsupported claims.
- Links point to public destinations.
- The banner remains readable at GitHub's rendered width.
- Required assets exist and all SVG files are valid XML.
